# 冬天一到腰就痛？不是老毛病，是你没做对这些事

> 更新时间：2026-09-17 (UTC+8)

**
WINTER

MEMORY

冬天来临，气温骤降

低温会让腰部肌肉痉挛、椎间盘血液循环减慢

腰椎间盘突出症急性发病率激增

不要慌！

这份养护攻略请收好

让你的腰椎安稳过冬！

攻略1：要温度再要风度！

冬天的腰椎更脆弱！

腰椎间盘就像腰椎间的“减震垫”，外层是坚韧的纤维环，内部是柔软的髓核。

冬季低温会让腰部肌肉收缩僵硬，纤维环弹性下降，再加上久坐、久站、损伤等，纤维环发生破裂，髓核向外突出，压迫神经引发疼痛、麻木等症状。

为了你的腰椎，一定要先选温度再要风度哦！

1.穿搭护腰：优先穿高腰加绒裤、长款羽绒服，腰部不外露；衣裤弹性适宜，避免过紧影响血液循环；

2.环境控温：别让冷风直吹腰腹，室内温度≥25℃，久坐时可放暖水袋在腰后，避免肌肉僵硬；

3.日常细节：洗澡后及时擦干腰部，头发吹干再出门；夜间睡觉穿高腰睡衣，床边备条薄毯，防止翻身时腰部受凉。

攻略2：坐卧行有讲究，合理不伤腰！

久坐不“费腰”，30分钟必动！

久坐时腰椎压力是站立时的1.5倍，弯腰久坐更是高达2.7倍，冬季肌肉僵硬会让损伤加倍。

- 
选对椅子：带腰托的办公椅最佳，腰托贴合腰椎自然曲度（约一拳距离），无腰托就用卷起的毛巾垫腰，给腰椎“撑腰”；

- 
调对高度：椅子升高到膝盖与髋关节呈 90°，双脚平放地面，杜绝跷二郎腿、“葛优躺”；

- 
定时活动：每坐30-45分钟就起身5分钟，做简单拉伸（双手叉腰转腰、靠墙静蹲），促进腰部血液循环，减少椎间盘压迫。

正确睡姿=腰椎“SPA”！

- 
床垫选中等硬度：过软会让腰部塌陷、脊柱弯曲，过硬则肌肉紧绷，此外，床垫的硬度可直接影响睡眠质量，与硬质的木板床和软质的海绵床垫相比，中等硬度的弹簧床垫较利于获得良好的睡眠。

- 
睡姿有讲究：仰卧时膝下垫薄枕，让膝关节微屈，腰部肌肉放松；侧卧时两腿间夹枕头，避免腰部扭曲；坚决不俯卧，会加重腰椎弯曲。

小心行走与搬物，腰椎少受罪！

- 
行走：雪天或结冰路面，双脚分开与肩同宽，重心放低，避免滑倒扭伤腰部；日常走路抬头挺胸，腰部保持自然曲线，不弯腰驼背

- 
搬物：搬重物前先搓热腰部肌肉，采用 “屈膝下蹲、用腿发力” 的姿势，物品贴近身体，避免弯腰扭转；取低处物品时下蹲而非弯腰，减少腰椎 “剪切力” 损伤

# 浙大妇院生孩子体验到底如何？真相在这里！

> 更新时间：2026-09-17 (UTC+8)

“你好，我要找院长。”一个平常工作日的上午，一位女士来到院长办公室所在的楼层，手里还拿着一个信封。

保安有些警惕地问：“你找院长干什么？”

“我这里有一封感谢信，非常想亲手交给院长。我女儿在这里生孩子，医生护士都照顾得非常好，我想当面谢谢他。”

她一边说着，一边把手里的信封拆开，给保安看信上的内容。保安就把她带到了党委书记、院长吕卫国的办公室。

这位女士姓季，她的女儿刚刚在产科一体化病房生下二胎。2017年，她的女儿也是在这里生下了第一个宝宝。

说起这两次生孩子的经历，季女士满满的感激。
季女士记得几乎每一个医护人员的名字
“你们的医生和护士真的非常专业，做得非常好，这两次都能平平安安地顺产，我们真的非常感激。”因为自己也做思政方面的工作，季女士还特别提到：“你们医院应该也在搞‘不忘初心，牢记使命’教育吧，你们的医生护士真的是做到了不忘初心啊！”

在繁忙的工作中听到患者这样的感谢，党委书记、院长吕卫国也很激动。

对于医生来说，治病救人是职业本分，但是听到患者家属的感谢还是非常开心，但其实对于季女士来说，她压根不知道浙大妇院的院长叫什么，长什么样。

“我女儿生孩子看的专家韩秀君我不认识，我一次也没见过她。但是我对医生们非常感激，所以这封信请一定要让韩主任看到，我真的很感谢她。”

说起季女士女儿王禾子跟韩秀君主任医师的缘分，还要回到2017年，王禾子生一胎的时候。那时候她听到身边很多人说，生孩子特别遭罪，尤其是不少顺转剖的，真当是受了两份罪，痛苦值加倍。

“当时我就想，与其顺产不成再去剖，还不如就直接剖腹产好了。”王禾子的这个念头，被当时接诊的韩秀君医生给掐灭了——医生并不是一味地说顺产有多好，而是认真仔细地测量了王禾子的骨盆、腹围，又结合着B超提示的宝宝大小等情况，跟王禾子进行综合分析，认为顺产这个方案能行。

尽管如此，女人生孩子怕痛的担心还是无法避免的。

王禾子生一胎的那天是个周六，韩秀君恰好不上班。随着破水和阵痛的来临，王禾子非常紧张，又很害怕，她的妈妈季女士给韩医生打了三个电话，每一个电话都得到了非常耐心的解释。也正是这几个电话，让王禾子对顺产更有信心了。

那天在医院值班的栗宝华医生也根据王禾子的情况，动员她尽量自然分娩。医生们的鼓励，护士们的指导，都让王禾子的顺产之路增加了一些保障。“当时我看到一会儿进去一个人，一会儿进去一个人，还以为我女儿出了什么事，担心得很。”季女士回忆，“后来才知道，她们都是进去给我女儿帮忙的，”呼吸、用力，生孩子也需要技巧。

在医护人员的指导下，3个多小时，王禾子就顺利生下了一个小公主。担心的“顺转剖”没有发生，产后的护理，给宝宝指导母乳喂养、洗澡都很贴心。“我们后来也去了别的产后机构，真真切切感到一体化病房的性价比真的高。”

所以，当王禾子要生二胎的时候，一家人还是首选浙大妇院一体化病房。当时一胎顺产之后，韩秀君跟王禾子说，“生二胎还来我这里”，所以王禾子也还是抢到韩秀君的号子，继续让她为二胎保驾护航。

虽然有了一胎的经历，但王禾子还是难免紧张。那天是下午6点多开始有了反应，7点多开始阵痛频繁。王禾子想打无痛针，麻醉科马上开始准备；导乐师本来正在吃饭，撂下饭碗就来给王禾子做导乐——产妇在剧痛之时，有些呼吸和发力的动作不利于宝宝顺利娩出，通过导乐师的指导，不仅可以帮助产妇更好地用力，也可以平静心情甚至减缓疼痛，让自然分娩更加顺利。

这一次，王禾子用了1个多小时就迎来了她的第二个小公主，比生一胎的时候更加顺利。因为进展十分顺利，尽管已经做好了一切准备，最后麻醉师还是建议可以不用打“无痛针”。曾经写过一次表扬信的王禾子妈妈，这次又专门写了一封。

“我妈把阿姨叫过来，自己专门回去写‘作业’。”王禾子的妈妈季女士自己也是教师出身，这可能也是她完成的最有爱的作业之一。

王禾子夫妻和刚出生的二宝

季女士说，王禾子生下二宝的第二天，韩秀君医生曾经来病房看过她们，但是自己恰好不在。虽然没有见过韩秀君，但是在她心里，韩医生就像亲人一样。“我女儿特别喜欢她，关于生孩子的事情，我女儿就听医生的。可见医生护士对我女儿真的很好，让她非常信任。现在两次都这么顺利，我们真的是很感激的。”

所以季女士说，无论如何都一定要把这封信转交到韩秀君医生手里。后来，产一科护士长胡引做患者调查，让他们对医院做得不够好的地方提意见的时候，季女士说她提不出意见。

“我这个人如果有意见是肯定会说的，但是我真的是没有什么觉得不好的地方了。”曾经也听说浙大妇院床位紧张，人多之类的传言，但是自己亲身体验之后，季女士觉得“真是来对了”。

“我现在跟周围人都推荐来浙大妇院，来一体化，是真的好。护士们太有耐心了，可以说是不厌其烦，有求必应。”

听到季女士和王禾子一家的感激之后，产一科护士长胡引也红了眼眶，有些感想。我“这么多年说真的，大年三十和年初一几乎从来没在家过过……”这样的浙大妇院人，这样的医护人员，还有很多。

8月19号是第二个全国医师节，是医生们的节日。

如果说医生们“不忘初心，牢记使命”，那么这初心，大概就是从成为医学生那一刻起，在心中埋下的治病救人的决心；

而使命，大概就是这平凡而又不凡的每一天里，这每一件细小而又伟大的事。

承受过，经历过，才更有触动。所以对于行医几十年的“老医生”吕卫国来说，患者的感谢同样让他激动不已。

**“如果医患关系都能像这样就好了！”**

这是党委书记、院长，也是医生吕卫国的感触，也是对这个医师节，我们想给出的最朴实，也最美好的注脚。
